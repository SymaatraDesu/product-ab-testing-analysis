# product-ab-testing-analysis

# E-Commerce A/B Testing & Product Funnel Analysis

## Описание проекта
В данном проекте проведен полный продуктовый анализ пользовательского поведения интернет-магазина. 
Цель исследования — оценить влияние нового дизайна карточки товара на конверсию в покупку (Conversion Rate) и финансовые показатели продукта (ARPU).

> **Примечание по данным:** В проекте используется синтетический датасет (эмулированный с помощью Python/NumPy), воссоздающий реальную мехинику e-commerce воронки и A/B-теста для демонстрации методологии продуктового анализа и проверки статистических гипотез.

---

## Технологический стек
* **Python 3.12**
* **Pandas / NumPy** — предобработка данных, расчет продуктовых метрик и построение когорт.
* **SciPy (`stats`)** — проведение статистических тестов (t-test, проверка гипотез, $p$-value).
* **Matplotlib / Seaborn** — визуализация воронок конверсии и доверительных интервалов.

---

## Ключевые результаты и бизнес-эффект

### 1. Анализ воронки конверсии и когорт
* Выявлен ключевой этап потери пользователей в воронке: переход от просмотра карточки товара к оформлению заказа.
* Проведен когортный анализ удержания (Retention Rate).

### 2. Результаты A/B-тестирования
* **Контрольная группа (A):** $CR = 49.16\%$
* **Тестовая группа (B):** $CR = 57.23\%$
* **Абсолютный прирост (Lift):** **$+8.07\%$**
* **p-value:** $0.00000924$ ($< 0.05$) $\rightarrow$ Результаты статистически значимы, нулевая гипотеза $H_0$ отвергнута.
* **95% Доверительный интервал прироста:** **$[+4.51\%, +11.63\%]$**.

### 3. Финансовая оценка (при среднем чеке 2 500 сом)
* **ARPU Группы A:** $1\,228.96\text{ сом}$
* **ARPU Группы B:** $1\,430.69\text{ сом}$
* **Прирост ARPU (Incremental Revenue):** **$+201.73\text{ сом}$ ($+16.41\%$)** на каждого зашедшего пользователя.
